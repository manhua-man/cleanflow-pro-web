CleanFlow Pro 是否需要管理员权限？Does CleanFlow Pro require Administrator privileges?
常规检索、微信/企微专清和双击极速搜索无需管理员权限。但由于 NTFS MFT 裸盘直读与卷影快照 (VSS) 遍历涉及 Windows 存储卷物理句柄访问，右键选择“以管理员身份运行”将解锁完整的 MFT 毫秒扫描、ReFS 块克隆及深度系统垃圾清理功能。Basic search and standard cache cleaning do not require admin rights. However, bare-metal NTFS MFT reading and Volume Shadow Copy (VSS) access interact directly with physical volume handles, so running as Administrator unlocks maximum scanning speed and advanced governance capabilities.
Junction 软搬家会导致应用程序报错或找不到文件吗？Will Junction soft migration cause apps to crash or lose files?
绝对不会。NTFS Junction 是 Windows 操作系统原生的文件系统特性 (Reparse Point)。当将 C 盘目录搬迁至 D 盘并在原位置建立 Junction 后，操作系统的 I/O 管理器会在内核层透明重定向所有文件句柄，被搬迁的软件甚至 IDE 无法感知底层物理位置的变更。Never. NTFS Junctions are a native Windows file system primitive (Reparse Points). When a folder is migrated and linked via a Junction, the Windows I/O manager transparently resolves all path operations at the kernel level. Applications continue normal operations unaware of physical relocation.
CleanFlow Pro 是否会联网上传我的文件或检索历史？Does CleanFlow Pro connect to the cloud or collect my search history?
100% 绝对不会。CleanFlow Pro 坚守 100% 本地离线原则，内部没有任何遥测代码、统计上报或云端通信。所有文件索引、检索数据库与自愈规则全量保存在用户本机，支持任意安全软件进行网络行为抓包与离线审计。100% No. CleanFlow Pro operates strictly offline with zero telemetry, zero background analytics, and zero network reporting. All file indices and governance rules reside exclusively on your local machine.
