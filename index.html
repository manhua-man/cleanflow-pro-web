为什么 CleanFlow Pro 要彻底淘汰 tasklist 和 reg.exe 等外部命令？Why did CleanFlow Pro eliminate tasklist and reg.exe subprocesses?
传统小工具为了开发省事，经常在后台调用 tasklist.exe 遍历进程或 reg.exe 查询注册表。这不仅会频繁引发火绒、360 或 Windows Defender 等安全软件的主动防御拦截与弹窗报警，每次创建外部控制台进程还会带来 50~100 毫秒的高昂性能开销和控制台黑窗口闪烁。CleanFlow Pro 全量切换至 Windows 底层原生 Win32 API（CreateToolhelp32Snapshot、RegOpenKeyExW、ShellExecuteW），单次系统调用耗时缩减至 0.01~0.2 毫秒（提速数百倍），零子进程派生，彻底根绝杀软误报。Many utilities lazily spawn tasklist.exe or reg.exe in the background. This introduces 50-100ms process overhead, flashes black console windows, and triggers antivirus warnings. CleanFlow Pro replaced all external CLI calls with native Win32 APIs (CreateToolhelp32Snapshot, RegOpenKeyExW, ShellExecuteW), reducing latency to 0.01-0.2ms with zero antivirus false positives.
Docker / WSL2 的 VHDX 物理压缩是如何做到释放几十 GB 的？How does Docker/WSL2 VHDX compaction reclaim tens of gigabytes?
WSL2 和 Docker Desktop 在 Windows 上采用动态扩展虚拟磁盘 (ext4.vhdx)。当你在容器内下载大模型或编译后删除文件，Linux 内部空间释放了，但宿主机上的 .vhdx 文件并不会自动缩小，导致 C 盘被虚占几十 GB。CleanFlow Pro 直接在 Windows 宿主机底层执行原生 Optimize-VHD -Mode Full 与 diskpart 批处理，彻底抽干未分配扇区空洞，将连续物理空间无损归还 C 盘。WSL2 and Docker use dynamically expanding VHDX files. Deleting files inside containers does not automatically shrink the host file. CleanFlow Pro invokes host-level Optimize-VHD and diskpart scripts to reclaim unallocated blocks, restoring continuous free space to C:.
NTFS Junction 软搬家会导致应用程序找不到文件或崩溃吗？Will Junction soft migration cause apps to crash or lose files?
绝对不会。NTFS Junction 是 Windows 操作系统底层的原生文件系统特性 (Reparse Point)。当将 C 盘目录搬迁至 D 盘并在原位置建立 Junction 后，操作系统的 I/O 管理器会在内核层透明重定向所有文件句柄，被搬迁的软件甚至 IDE 无法感知底层物理位置的变更，且 CleanFlow Pro 支持双向一键安全回迁。Never. NTFS Junctions are native Windows kernel Reparse Points. The Windows I/O manager transparently resolves path operations at the driver level. Applications continue normal operations completely unaware of physical relocation.
全盘秒搜是否需要常驻后台消耗大量内存？Does instant search consume heavy background memory?
不需要。CleanFlow Pro 基于 Rust 高效内存布局与 MFT 裸盘直读，370 万条记录在内存中仅占用极低的物理常驻内存（远低于同类 Electron 或 Java 工具）。通过 Windows 原生目录变更通知自动更新索引，随叫随到，轻巧灵动。No. Leveraging Rust lean memory layouts and direct MFT streaming, indexing millions of records requires a minimal memory footprint—far lower than Electron or Java tools. Native directory change notifications keep the index up to date.
